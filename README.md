# 🛍️ AI Sales Assistant (GadgetKart)

An AI-powered e-commerce sales chatbot built using Streamlit, LangChain, LangGraph, and Google Gemini.  
It simulates a real-world WhatsApp-style shopping assistant that helps users browse products, check prices, track orders, and view offers.

---

## 🚀 Live Features

- 💬 WhatsApp-style chat UI (Streamlit)
- 🤖 AI-powered responses using Google Gemini (LLM)
- ⚙️ Tool-based agent system (LangGraph + LangChain)
- 🛒 Product listing and product details API
- 📦 Order tracking system
- 🎁 Active offers & pricing plans
- 🧠 Persistent memory using SQLite
- 🌤️ Clean modern UI with animated background

---

## 🧠 System Architecture

User → Streamlit UI → LangGraph Agent → LLM (Gemini)  
→ Tool APIs (Products / Orders / Offers) → Memory (SQLite)  
→ Response → UI
